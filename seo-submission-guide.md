# Sitemap Submission Guide

The sitemap is ready at:
- https://www.shield-assurance.com/sitemap.xml

## Google Search Console
1. Open: https://search.google.com/search-console
2. Select property: `https://www.shield-assurance.com/`
3. Go to `Sitemaps`
4. Submit: `https://www.shield-assurance.com/sitemap.xml`

Direct page after login:
- https://search.google.com/search-console/sitemaps?resource_id=https://www.shield-assurance.com/

## Bing Webmaster Tools
1. Open: https://www.bing.com/webmasters
2. Select property: `https://www.shield-assurance.com/`
3. Go to `Sitemaps`
4. Submit: `https://www.shield-assurance.com/sitemap.xml`

Direct page after login:
- https://www.bing.com/webmasters/sitemaps

## Notes
- Legacy sitemap ping endpoints now return deprecation errors (`404` for Google, `410` for Bing).
- Manual submission through Search Console and Bing Webmaster Tools is the reliable method.
- Re-submit sitemap after major URL additions.
